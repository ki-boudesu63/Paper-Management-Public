# styles — 投稿スタイル定義フォルダ

`config.yaml` の `paths.style_folder` に対応するフォルダです。

## 役割

投稿先の雑誌ごとに、Author Guidelines（著者向け規定）から起こした
**スタイル定義** `<雑誌名>.md` を置きます。

スタイル定義には、原稿のセクション構成・語数/文献数/図表数の上限・抄録の形式・
本文中の引用形式・文献リストの形式・一般スタイルなどが記載されます。

## 生成のしかた

スタイル定義は **AIエージェントが生成**します。投稿先雑誌の Author Guidelines を用意し、
`paper_management` フォルダで Claude Code / Codex / Gemini いずれかのCLIを起動して
「このガイドラインからスタイル定義を作って」と指示してください。

## 使われ方

`workspace/` で原稿を執筆・仕上げる際に、ここのスタイル定義が参照されます。
詳しい執筆ワークフローは `workspace/論文執筆ガイド.md` を参照してください。

## English

### styles — Journal Submission Style Definitions

This folder corresponds to `paths.style_folder` in `config.yaml`.

### Purpose

Place **style definition** files (`<JournalName>.md`) here, created based on the Author Guidelines of each target journal.

Style definitions include information such as manuscript section structure, word/reference/figure limits, abstract format, in-text citation format, reference list format, and general style rules.

### How to Generate

Style definitions are **generated by an AI agent**. Prepare the Author Guidelines of your target journal, launch Claude Code / Codex / Gemini CLI in the `paper_management` folder, and instruct it to "create a style definition from these guidelines."

### How They Are Used

When drafting and finalizing manuscripts in `workspace/`, the style definitions in this folder are referenced.
For detailed writing workflow, see `workspace/論文執筆ガイド.md`.

## 简体中文

### styles — 期刊投稿样式定义文件夹

此文件夹对应 `config.yaml` 中的 `paths.style_folder`。

### 用途

根据各目标期刊的 Author Guidelines（作者须知），将生成的**样式定义**文件 `<期刊名>.md` 放置于此处。

样式定义包含稿件的章节结构、字数/参考文献数/图表数上限、摘要格式、正文引用格式、参考文献列表格式及一般排版规则等信息。

### 生成方式

样式定义由 **AI 代理自动生成**。请准备好目标期刊的 Author Guidelines，在 `paper_management` 文件夹中启动 Claude Code / Codex / Gemini CLI，并指示其"根据该指南创建样式定义"。

### 使用方式

在 `workspace/` 中撰写和定稿时，会参考此文件夹中的样式定义。
详细的写作工作流程请参阅 `workspace/論文執筆ガイド.md`。
