# styles — 投稿スタイル定義フォルダ

`config.yaml` の `paths.style_folder` に対応するフォルダです。

## 役割

投稿先の雑誌ごとに、Author Guidelines（著者向け規定）から起こした
**スタイル定義** `<雑誌名>.md` を置きます。

スタイル定義には、原稿のセクション構成・語数/文献数/図表数の上限・抄録の形式・
本文中の引用形式・文献リストの形式・一般スタイルなどが記載されます。

## 生成のしかた

スタイル定義は **AIエージェントが生成**します。投稿先雑誌の Author Guidelines を用意し、
`paper_management` フォルダで Claude Code / Codex / Gemini いずれかのCLIを起動して
「このガイドラインからスタイル定義を作って」と指示してください。

## 使われ方

`workspace/` で原稿を執筆・仕上げる際に、ここのスタイル定義が参照されます。
詳しい執筆ワークフローは `workspace/論文執筆ガイド.md` を参照してください。
