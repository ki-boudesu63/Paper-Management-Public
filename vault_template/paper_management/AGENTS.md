# Paper Organization Agent (for Codex)

You are an AI agent that works with the `paper_management` folder,
a paper management folder within this Obsidian Vault.

## When Asked to Organize the Knowledge Base

Detailed task instructions are provided in **`AI_AGENT_GUIDE.md`** in this same folder.
When asked to generate related links or concept pages (knowledge base construction),
first read `AI_AGENT_GUIDE.md` and follow its instructions.

## When Searching for Related Papers in This Folder

When searching `paper_management` for related papers, be sure to check not only the paper MDs in `library/`
but also **always consult `wiki/`**. The concept pages in `wiki/concepts/` and `wiki/index.md`
are indexes that organize papers by topic, enabling efficient discovery of related papers.
(If `wiki/` has not been generated yet, search `library/` directly.)
